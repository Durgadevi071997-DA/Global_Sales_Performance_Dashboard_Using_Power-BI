
# Global Sales Performance Dashboard Using Power BI


## Project Overview

The Global Sales Performance Dashboard is an interactive Business Intelligence project developed using Microsoft Power BI. The purpose of this project is to analyze sales performance using a global sales dataset containing information about regions, countries, item types, sales channels, revenue, cost, and profit. The dashboard presents business information through interactive visualizations, enabling users to monitor sales trends, compare regional performance, analyze product categories, and evaluate profitability. This project helps organizations make informed decisions by transforming raw sales data into meaningful visual insights.

## Business Objectives

The main objectives of this project are:

To import and analyze sales data using Power BI.

To visualize sales performance by Region, Item Type, and Month.

To monitor key business metrics such as Total Revenue, Total Profit, and Units Sold.

To build an interactive dashboard using charts, cards, and slicers.

To generate business insights that support data-driven decision-making.

## Tools and Technologies Used

The following tools were used to complete this project:

Microsoft Power BI Desktop – Dashboard development and visualization.

CSV Dataset – Global Sales dataset used for analysis.

DAX (Data Analysis Expressions) – Used to create calculated columns such as Month-Year.

Power Query Editor – Used for data cleaning and transformation.

Microsoft Excel (Optional) – Used for reviewing and validating the dataset before importing into Power BI.
## Findings

The dashboard provides a clear overview of global sales performance.

Revenue and profit can be monitored using interactive KPI cards.

Regional analysis helps identify high-performing and low-performing markets.

Product-wise analysis highlights the best-selling item types.

Interactive slicers allow users to filter data by region, product, and sales channel for detailed analysis.
## Business Insights

Business insights summarize the key findings obtained from the dashboard. These observations help management understand sales performance and support strategic decision-making.

Insights

The highest revenue was generated by the best-performing region.

Office Supplies contributed the highest total revenue.

Offline sales generated more revenue than online sales.

Monthly revenue showed noticeable fluctuations during the reporting period.
## Outcome of Project

After completing this project, the following skills were achieved:

Imported and transformed sales data into Power BI.

Created calculated columns using DAX.

Developed interactive visualizations using Line, Bar, and Donut Charts.

Designed a professional dashboard with KPI cards and slicers.

Generated meaningful business insights from sales data.

Improved skills in data visualization, dashboard design, and business analytics using Power BI.

## Conclusion

This project successfully demonstrated how SQL and Python can be integrated to perform sales data analysis. Using SQLite, Pandas, and Matplotlib, meaningful insights were generated from sales data, and the results were effectively visualized through a bar chart.
